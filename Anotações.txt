🚦 QUANDO USAR IF, ELSE, WHILE E FOR
A. if / elif / else (O Tomador de Decisão)
Ele NÃO repete nada. Ele apenas escolhe um caminho uma única vez e segue em frente.

***Quando usar: Quando você precisa fazer uma pergunta e bifurcar o caminho do código.

Analogia: "Se chover, levo guarda-chuva. Senão, vou de óculos de sol.
chovendo = True
if chovendo == True:
    print("Levo o guarda-chuva ☔")
else:
    print("Vou de óculos de sol 🕶️")


B. for (O Contador / O Viajante)
Ele repete algo, mas você sabe exatamente quando ele vai parar. Ele sempre tem um limite claro,
 seja um número exato de vezes ou o tamanho de uma lista.

Quando usar: Quando você quer passar por cada item de uma lista (como o seu carrinho de compras) ou repetir um código
 um número exato de vezes (ex: do 1 ao 10).

Analogia: "Leia as próximas 5 páginas deste livro." (Você sabe exatamente quando vai acabar).
clientes = ["Lorenzo", "Ana", "Carlos"]
for nome in clientes:
    print(f"Enviando email de boas-vindas para: {nome}")
print("-" * 20)

# Exemplo Prático 2: Repetindo número exato de vezes (Contador)
# O range(1, 6) vai contar do 1 até o 5.
for pagina in range(1, 6):
    print(f"Lendo a página {pagina} de 5...")
C. while (O Sentinela)
Ele repete algo até que uma condição mude, não importa quantas vezes precise rodar. Você não sabe quando ele vai parar.

Quando usar: Quando a repetição depende de uma ação externa (como o usuário digitar uma senha correta, ou escolher "Sair" do programa).

Analogia: "Continue lendo o livro até você pegar no sono." (Pode demorar 2 páginas ou 50 páginas, você não sabe o número exato, só sabe a condição de parada).

Python
# Exemplo Prático: Tela de Login
senha_correta = "admin123"
senha_digitada = "" # Começa vazia para forçar a entrada no loop

# O loop continua rodando ENQUANTO a senha digitada for DIFERENTE da correta
while senha_digitada != senha_correta:
    senha_digitada = input("Digite a senha para acessar o sistema: ")
    
    if senha_digitada != senha_correta:
        print("Senha incorreta! Tente novamente.\n")

# Quando ele acertar a senha, o while é quebrado e o código cai aqui embaixo:
print("Acesso Liberado! Bem-vindo ao sistema. 🔓")
